Repositorio Web Multimedia

Plataforma estática de transferencia y gestión del conocimiento para la asignatura de Multimedia. Espacio diseñado para consulta activa del temario y facilitación de aportaciones para futuras generaciones politécnicas.

🎯 Propósito y Alcance del Repositorio

Este repositorio ha sido concebido para centralizar el contenido teórico, práctico y metodológico de la materia de Multimedia impartida en la UPIICSA. La arquitectura del sistema permite que estudiantes actuales consulten los fundamentos de la producción digital y que las generaciones venideras puedan expandir, corregir o enriquecer el temario con facilidad.

💡 Filosofía de Diseño: Web Vanilla y Sostenible
Construido íntegramente con HTML5 semántico, CSS3 puro y un mínimo de JavaScript. No depende de servidores dinámicos ni dependencias pesadas, lo cual garantiza que pueda alojarse permanentemente en GitHub Pages sin costos de mantenimiento.

🗺️ Organización de las Unidades Temáticas

Unidad I: Contexto y Fundamentos
Elementos multimedia, evolución histórica gráfica, formatos digitales (audio, video, imagen, texto), etapas de producción, semiología visual y bases de la animación hacia la realidad virtual.
Unidad II: Tecnologías Emergentes
Realidad Virtual (RV), Realidad Aumentada (RA), recorridos virtuales, motores de videojuegos (Unity, Unreal Engine), lenguajes de desarrollo web y computación gráfica (OpenGL, OpenCV, Python).
Unidad III: Integración y Autoría
Edición no lineal de video, herramientas de postproducción, software de autoría y originalidad, marco legal y registro de derechos de autor (INDAUTOR), así como proyectos disruptivos.

🛠️ Guía para Futuros Alumnos: ¿Cómo agregar o editar contenido?

Para mantener el repositorio actualizado, cada tema cuenta con su propio archivo en la carpeta /vistas/. Si deseas agregar notas de clase, códigos o ejemplos prácticos, sigue estos pasos:

  1. Localiza el archivo correspondiente: Abre el archivo con el código del tema que deseas enriquecer (por ejemplo: vistas/1-1-1-elementos.html).
  2. Ubica la Zona de Contribución Estudiantil: Hacia el final de cada archivo encontrarás una sección delimitada por comentarios HTML.
  3. Inserta tu material: Puedes usar párrafos <p>, listas, tarjetas <div class="concept-item">, o bloques de código sin alterar la estructura base ni los estilos de css/vista.css.
  4. Envía tu contribución: Realiza un Pull Request al repositorio de GitHub para que los profesores o administradores integren tus mejoras.
✅ Buenas Prácticas Politécnicas
Asegúrate de citar fuentes confiables, respetar los derechos de autor de las imágenes o videos incluidos y mantener un lenguaje técnico y académico.
